# AI-Based Spam Message Detection

## Project Overview
This project uses Machine Learning and Natural Language Processing (NLP) techniques to classify text messages as **Spam** or **Not Spam (Ham)**. The system analyzes the text and predicts whether a message is unwanted or legitimate.

## Objectives
- To detect spam messages automatically using machine learning.
- To preprocess and transform text data into numerical features.
- To train and evaluate a classification model.
- To improve the identification of unwanted messages.

## Technologies Used
- **Programming Language:** Python
- **Platform:** Google Colab
- **Libraries:** Scikit-learn, Pandas, NumPy
- **NLP Technique:** TF-IDF Vectorization
- **Machine Learning:** Classification

## Project Workflow
1. Load the message dataset.
2. Clean and preprocess the text data.
3. Convert text into numerical features using TF-IDF Vectorization.
4. Train the machine learning model.
5. Evaluate the model using appropriate performance metrics.
6. Predict whether a new message is spam or legitimate.

## Features
- Automated spam message classification.
- Text preprocessing and feature extraction.
- Machine learning-based prediction.
- Reusable trained model and TF-IDF vectorizer.

## Project Files
- `AI_Based_Spam_Message_Detection.ipynb` — Jupyter notebook containing the project code and workflow.
- `spam_detection_model.pkl` — Saved machine learning model.
- `tfidf_vectorizer.pkl` — Saved TF-IDF vectorizer.

## How to Run
1. Clone or download this repository.
2. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Install the required Python libraries if they are not already installed.
4. Upload or provide the dataset required by the notebook.
5. Run the notebook cells in order.

To use the saved model for predictions, load the trained model and TF-IDF vectorizer using Python's `pickle` module.
